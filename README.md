# Math Recall

高校数学の問題ごとに理解度を記録し、学習状況に合わせて次回復習日を自動計算するWebアプリです。サーバーや外部ライブラリは不要で、GitHub Pagesでもそのまま動作します。

## ファイル構成

```text
.
├── index.html   # ダッシュボード、登録・復習ダイアログ
├── style.css    # レスポンシブUIとダークモード
├── script.js    # 保存、検索、復習アルゴリズム、入出力
└── README.md    # この説明ファイル
```

## 主な機能

- 5段階の理解度、復習履歴、連続成功回数を問題ごとに記録
- 理解度の推移、前回からの経過、つまずき傾向に応じた可変復習間隔
- 今日・期限超過・苦手問題を優先したダッシュボード
- 週表示／月表示を切り替えられる復習カレンダー
- 青チャートの単元を科目別に検索・選択できる問題登録フォーム
- 科目、単元、理解度、状態による絞り込みと検索
- localStorageへの自動保存、JSONバックアップ／復元
- PC・スマートフォン対応、ライト／ダークモード

## Webアプリの起動方法

1. このフォルダで簡易Webサーバーを起動します。

   ```bash
   python3 -m http.server 8000
   ```

2. ブラウザで次のURLを開きます。

   ```text
   http://localhost:8000
   ```

または `index.html` を直接開けます。外部通信は行いません。

## 復習間隔の考え方

`calculateReviewSchedule()` は画面処理から独立した純粋関数です。理解度0〜2は短く、3〜4は成功が続くほど長く設定します。理解度4から0〜1へ下がった場合は忘却として翌日に戻し、低理解度が続く場合は最大2日以内に制限します。

ブラウザの「データ管理」からサンプル4問を追加すると、期限超過・苦手判定・理解度分布をすぐに確認できます。
